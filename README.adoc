Canonry is an Agda theory for the verification of Chapel array programs.
It holds a calculus of strided one-dimensional domains and a weakest-precondition core.
The target is the first tier of proof: no index out of bounds, no nil dereference and no division by zero.
With that tier proved, the run-time checks for these faults could be switched off.
The repository was created on 2026-11-12 and is at an early stage.

== Status

The base milestone (M0) is done. Work is parked until the next milestone starts.
The model has integers, strided 1D domains, integer and Boolean expressions with `select`, stores, and six statements: `skip`, `assign`, `arrRd`, `arrWr`, `seq` and `ifS`.

M0 proves these theorems in `Canonry/Core.agda`:

* `substA-sound`, `substB-sound`, `substArrA-sound` and `substArrB-sound`: substituting in a condition agrees with updating the store.
* `wp-progress-safe` and its instance `vc-progress-safe`: if `wp Δ s Q` is true in a store, then `s` is `skip` and `Q` is true, or the configuration takes one step and the remaining condition is true in the new store.

An `arrRd` or `arrWr` statement has a step only when its index lies in the domain of the array.
So a true condition means that the next array statement is in bounds.

Not proved yet:

* A full run. The theorem covers one step, and `Step` is not proved deterministic.
* Loops. The module has no loop statement.
* Procedures, n-dimensional domains, nil checks, division and the 64-bit range.
* Any link to real Chapel code or to a condition generator in code.

Proof grade: `ungraded`. The claim CAN-1 has no receipt, no Rocq leg and no Lean leg yet.
The row is in link:docs/status/PROOF-STATUS.adoc[docs/status/PROOF-STATUS.adoc].

== Check the proofs

[source,bash]
----
bash scripts/check-proofs.sh agda
----

The script checks each module listed in `verification/proofs/agda/MANIFEST`.
The canonical flags are `agda --safe --without-K --cubical-compatible`.
The sample module `Properties.agda` was checked with Agda 2.6.3 and standard library 1.7.3.
`Canonry/Core.agda` imports no library and has no postulate.
The workflow `.github/workflows/canonry.yml` runs the same command in CI.

== Layout

* `verification/proofs/agda/Canonry/Core.agda`: the Canonry theory.
* `verification/proofs/agda/Properties.agda`: a sample module from the repository template. It is not Canonry theory.
* `verification/proofs/agda/MANIFEST`: the list of modules that the check gates.
* `docs/status/`: roadmap, proof status and readiness records.
* `scripts/` and `tests/`: estate tooling and its shell tests.
